## Image Specifications

### Hero Images
- **Size:** 1920x1080 or larger
- **Format:** WebP with JPG fallback
- **Style:** Abstract tech illustrations or real platform screenshots

### Case Study Images
- **Size:** 800x600 (4:3 ratio)
- **Format:** WebP with JPG fallback
- **Style:** Dashboard screenshots, architecture diagrams, or illustrated concepts

### Icons
- **Hub Icons:** 64x64px, SVG format, consistent style
- **Service Icons:** 48x48px, SVG format, Lucide or custom
- **Stats Icons:** 32x32px, SVG format

### Consultant Photo
- **Existing:** `/public/david_headshot.jpg`
- **Size:** 400x400px
- **Format:** JPG

---

## Recommended Image Sources

1. **Unsplash** - Free tech/computer photos
2. **Undraw** - Free illustrations
3. **Icons8** - Icons and illustrations
4. **Figma Community** - Icon sets
5. **Custom Screenshots** - AWS/Azure consoles, dashboards

## Current Placeholders

All pages currently use:
- Lucide React icons (SVG, scalable)
- Gradient backgrounds
- Colored icon containers (bg-blue-50, etc.)
- Text-based placeholders where images would go

To replace with real images:
1. Add images to `/public/` folder
2. Replace `<div className="bg-gray-100...">` placeholders with `<img>` tags
3. Update icon components with custom SVGs if needed
