## Coding Rules

### Path Aliases
- **Always use `@/` aliases** for cross-directory imports (e.g., `@/hooks/useInView`, `@/styles/carbon-typography.css`, `@/sections/Footer`).
- **Never use deep relative paths** like `../../../../hooks/...` — they break on any folder move.
- Sibling imports (`./`, `../`) are acceptable for files within the same module/package.

### Typography
- **Single source of truth**: `app/src/styles/carbon-typography.css`
- Use `.carbon-fluid-display-03`, `.carbon-body-02`, `.carbon-label-02`, etc. — never raw Tailwind utilities like `text-2xl font-semibold`.
- Load `carbon-typography.css` **once per page** (in the page's `index.tsx`). **Never import it in individual section components.**

### Performance
- Heavy pages (>500 KB JS) **must use route-level code splitting**: `const Page = lazy(() => import('@/pages/services/PageName'))`.
- Wrap lazy routes in `<Suspense fallback={...}>`.

### Git Hygiene (NEVER commit these)
- `app/dist/` — build artifacts
- `app/node_modules/.vite/` — Vite dependency cache
- `.env.local` — environment secrets
- `app/backups/` — local snapshot files
- Add new exclusions to root `.gitignore`.
